# Help shape useful AI work

This repository welcomes product questions, reproducible feedback, clearer documentation and non-confidential use cases. The application source is private, so we are not currently accepting application-code pull requests here.

- Start an open-ended conversation in Discussions.
- Use the bug form for something you can reproduce; specify the product version or demonstration involved.
- Use the feature form to explain the outcome you need, not just a requested button.
- Submit documentation corrections as a pull request. Describe the change and the evidence behind it.

Do not include access tokens, customer records, private prompts, screenshots containing personal information or commercial terms. Contact the maintainer privately for pilot details.

We will consider requests against usefulness, available evidence and implementation scope. No response-time or feature-delivery commitment is implied.
