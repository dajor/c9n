# Publication and licence status

This repository publishes product documentation, demonstration screenshots and planning worksheets. The underlying application source is currently private and is not included in this repository.

No open-source licence has been selected or granted for the application, extracted workflow components, branding or other third-party material. Public visibility is not a product source-code release. Please contact the maintainer before reusing material beyond the permissions applicable on GitHub.

c9n stands for Cooperation. The public product site is https://c9n.app. Screenshots show synthetic demonstration data. Third-party source repositories, customer data, credentials and original reference videos are excluded.

The public download contains a versioned Docker installer with configuration, instructions and checksums. The application image is supplied separately for guided pilot testing and is not included in the public installer download.
