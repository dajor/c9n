# c9n: cooperation is the idea

c9n stands for **cooperation**: c + nine letters (ooperatio) + n. People, knowledge and AI working together. The community aims to extend this cooperation beyond individual organisations.

## Your installation remains independent

Design, knowledge, projects and workflows run in your own c9n installation. Your models and directly connected providers do not require a c9n community connection. GPU sharing is an optional extension, not a prerequisite for using the product.

## Build together

We can already discuss processes and use cases, collect feedback and shape priorities together. [Join the discussion](https://github.com/dajor/c9n/discussions). The public repository contains product information and community materials; application source remains private for now.

## Planned GPU sharing

Participants with spare GPU capacity should be able to offer selected models to others. The operator chooses recipients, availability, limits and pauses. Other installations should be able to select these models for suitable tasks. A larger or more expensive model is not automatically the right choice for every task.

A small central gateway is intended to coordinate connections, permissions and later usage accounting. The application and model computation remain on participants’ infrastructure. Only explicitly selected requests are transferred; a community request's inputs can technically be accessed by the gateway and the model operator. Entire knowledge stores or local user accounts are not automatically synchronised. Participation is intended to be disabled by default.

## Credit concept

Confirmed computing work could earn credit towards model requests from other community members. Model class, effort and quality should inform transparent rules. Duplicate charges, failed requests and disputed usage evidence must be handled. Tariffs and allocation rules are not fixed. There is currently no usable credit system.

## Status: 21 September 2026

The central gateway foundation is deployed. Public OAuth activation and the complete live account-connection test are still pending. Model sharing between independent installations, protection and provisioning of model endpoints, and credits remain future work. The website describes this product direction, not an available GPU marketplace.
