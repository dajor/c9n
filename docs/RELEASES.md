# 0.1.0-alpha.1

First versioned c9n self-hosting pilot package, based on the existing tested prototype.

Includes the local application, first-administrator setup, Standard/Advanced workflow editors, organisational design, knowledge, model connections and measurement surfaces in the separately supplied application image. Installer uses a persistent data volume and loopback-only access. Exact image ID and SHA-256 download checksums accompany the release.

Known limits: early alpha, guided testing; Linux amd64 only; no central community gateway, automatic model sharing or live credit economy; no automatic upgrades. Specific workflow/provider capabilities remain bounded by the application. A customer production rollout requires its own recovery and workflow acceptance tests.
