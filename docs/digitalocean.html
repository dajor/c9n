c9n auf DigitalOcean installieren

Euer eigener Server für Design, Wissen und Workflows.

Du brauchst ein DigitalOcean-Konto, einen SSH-Schlüssel sowie das separat bereitgestellte c9n-Pilotimage und den passenden Installer derselben Version. Der öffentliche Download enthält bisher nur den Installer. Fordere das Image an, bevor du einen kostenpflichtigen Server erstellst.

Deploy on DigitalOcean ↗

  1. Docker-Server erstellen

    Der Button öffnet die offizielle Docker-Droplet-Vorlage. Wähle einen Linux-amd64-Server, Rechenzentrumsregion und SSH-Schlüssel. Prüfe den angezeigten Preis und entscheide über Backups, bevor du den Server erstellst. Als Ausgangspunkt für einen kleinen Test ohne lokale KI-Modelle empfehlen wir 2 GB RAM; der tatsächliche Bedarf hängt von euren Workflows ab.

  2. Installationspakete übertragen

    Lade Installer, Anwendungsimage und beide Prüfsummendateien derselben Version auf den Server. Melde dich per SSH an. Prüfe die Pakete vor dem Entpacken:

    sha256sum -c SHA256SUMS-installer.txt
sha256sum -c SHA256SUMS-application.txt

    Prüfe anschließend, dass Docker und Compose verfügbar sind:

    docker --version
docker compose version

  3. c9n installieren

    Entpacke den Installer in ein neues Verzeichnis und lade das Anwendungsimage. Ersetze VERSION durch die Versionsnummer deines Pakets. Starte danach im entpackten Installer-Verzeichnis:

    docker load -i /pfad/c9n-app-VERSION-linux-amd64.tar.gz
sh install.sh
docker compose ps

    Der Installer legt einen individuellen Verschlüsselungsschlüssel und ein dauerhaftes Datenvolume an.

  4. Ersten Administrator einrichten

    Öffne auf deinem eigenen Rechner einen SSH-Tunnel. Ersetze SERVER_IP durch die Adresse des Droplets:

    ssh -N -L 8765:127.0.0.1:8765 root@SERVER_IP

    Öffne danach http://127.0.0.1:8765 im Browser und lege deinen Administrator an. Port 8765 bleibt vom Internet aus geschlossen.

  5. Teamzugang und Sicherung einrichten

    Für den Teamzugang richte deine Domain und einen HTTPS-Reverse-Proxy ein. Setze COOKIE_SECURE=1 in der Compose-Konfiguration und erstelle den App-Container neu. Sichere Datenvolume und .env gemeinsam. Modellanbieter werden anschließend in c9n unter Verbindungen eingerichtet; Modelle laufen nicht automatisch auf diesem Server.

Vollständige Installationsanleitung →

Warum ein Droplet? c9n verwendet derzeit eine lokale Datenbank und Dateien. DigitalOcean App Platform bietet keinen dauerhaften lokalen Speicher und unterstützt keine Volumes. Deshalb führt dieser Button zur Docker-Droplet-Einrichtung. DigitalOcean: App Platform limits ↗
