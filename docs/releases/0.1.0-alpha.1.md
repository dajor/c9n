First semantically versioned c9n installation package: **0.1.0-alpha.1**.

**This public ZIP contains the installer and instructions, not the application image.** The application remains private and is supplied separately to approved pilot customers. Request access at https://c9n.app/#contact.

- Docker Compose configuration for Linux amd64, with loopback-only access and persistent data.
- First-administrator setup, without preconfigured accounts.
- Installer verifies the exact application image ID and refuses to overwrite an existing configuration.
- German/English installation and update guidance; SHA-256 checksum attached.
- Community gateway, GPU sharing and credits are planned, not enabled by this package.

Download `c9n-installer-0.1.0-alpha.1.zip` and `SHA256SUMS-installer.txt`. Verify using `sha256sum -c SHA256SUMS-installer.txt`, then follow the included guide. GitHub's automatic source archives contain only this public product repository.

Tested: production image build, first-owner setup on an isolated Docker volume, health/version/assets/editors, persistent account after restart. Early alpha for guided testing, not a production-readiness guarantee.
