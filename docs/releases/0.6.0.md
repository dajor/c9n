# c9n 0.6.0

## Updates mit einem Klick unter Einstellungen → Hosting

Unter **Einstellungen → Hosting** prüft „Nach Updates suchen“ jetzt, ob eine neue
Version bereitsteht, und bietet sie an. Nach deiner Bestätigung lädt c9n die Version,
prüft Prüfsummen und Image, sichert deine Daten, startet die neue Version und lädt die
Seite danach selbst neu. Du musst dafür nichts auf dem Server tun.

Möglich macht das ein zweiter kleiner Container, der **Update-Dienst**. Er läuft neben
der Anwendung und wird bei jedem Update mit aktualisiert. Die Anwendung selbst hat
weiterhin keinen Zugriff auf Docker; sie gibt nur deinen Klick an den Update-Dienst
weiter.

## Releases sind öffentlich

Neue Versionen erscheinen ab jetzt im öffentlichen Repository `dajor/c9n`, mit Installer
und Anwendungsimage. Der Update-Dienst braucht deshalb keinen GitHub-Zugang. Wer Releases
aus einem privaten Repository bezieht, kann auf der Hosting-Seite einen Lesezugang
hinterlegen; er wird geprüft, nur auf dem Server gespeichert und nie wieder angezeigt.

## Geändert

- Ohne verbundenen Update-Dienst behauptet die Hosting-Seite nicht mehr, es gebe keine
  neuere Version.
- Fehler des Update-Dienstes stehen mit ihrer Ursache auf der Hosting-Seite.

## Einmalig für bestehende Installationen

Installationen vor 0.6.0 richten den Update-Dienst einmal ein (siehe `UPDATES.md` im
Installer). Danach kommen alle weiteren Versionen über die Hosting-Seite.
