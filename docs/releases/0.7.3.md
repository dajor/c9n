# c9n 0.7.3

## Update-Dienst: GitHub-Abfragegrenze

GitHub erlaubt ohne Anmeldung 60 Abfragen pro Stunde. Der Update-Dienst hat bei jeder
Prüfung für jede Version einzeln nachgefragt und diese Grenze aufgebraucht. Dann meldete
er fälschlich „Releases liegen in einem privaten Repository“ und bot kein Update an.

- Eine Prüfung braucht jetzt eine Abfrage statt sechs bis acht; eine unveränderte Liste
  kostet nichts.
- Ist die Grenze doch erreicht, steht auf der Hosting-Seite „GitHub-Abfragegrenze erreicht.
  Der nächste Versuch klappt ab HH:MM Uhr.“

Enthält alles aus 0.7.2.
