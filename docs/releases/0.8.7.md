# c9n 0.8.7

## Alles passt auch auf dem Handy

- **Umschalter** („Nur lokal / Cloud nach Freigabe“, „Wer darf freigeben“, Videoqualität) sind ein gemeinsamer Baustein.
  Auf schmalen Bildschirmen stehen die Optionen untereinander statt abgeschnitten oder dreizeilig umbrochen.
- **Überschriften mit Buttons:** Auf dem Handy rutschen die Buttons unter die Überschrift, statt über den Rand zu ragen
  (z. B. „Organisationsbild speichern“).
- **Workflow-Reiter** brechen nicht mehr um; auf dem Handy lassen sie sich seitlich wischen.
- Jede Version prüft vor dem Release alle Seiten am Desktop und in Handybreite: Buttons einer Reihe stehen bündig,
  kurze Beschriftungen brechen nicht um, keine Seite scrollt seitlich.
