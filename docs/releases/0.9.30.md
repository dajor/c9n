# c9n 0.9.30

Die Abläufe-Übersicht zeigt die benötigten Module jedes Prozesses als kleine Tags direkt unter seiner Beschreibung. So lässt sich zum Beispiel Jira erkennen, ohne den Ablauf zu öffnen.

Ausgeschaltete Module sind mit „aus“ gekennzeichnet. Ein eingeschaltetes Modul, dessen Erweiterung oder Arbeiter noch fehlt, zeigt „nicht bereit“. Die Auswahl unter Prozessdokumentation und der Zustand unter Einstellungen → Module bestimmen die Anzeige.

Beim Laden oder bei einer Lesestörung bleibt der Modulstatus ausdrücklich offen. Die Abläufe lassen sich weiterhin ansehen; „Aktualisieren“ liest den Zustand erneut. Prozesse ohne zusätzliche Module erhalten keine Tags.
