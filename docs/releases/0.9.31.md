# c9n 0.9.31

Der Reiter „Dokumentation“ heißt jetzt „Einstellungen“. Hier bleiben Kurzbeschreibung, Prozessdokumentation und die benötigten Module gemeinsam erreichbar.

Ein kleines Zahnrad in der Abläufe-Übersicht öffnet die Einstellungen des jeweiligen Prozesses direkt. Benutzer mit Bearbeitungsrechten können dort sofort Änderungen vornehmen und speichern. Andere Benutzer sehen die gespeicherten Werte.

Bestehende Prozesslinks funktionieren weiterhin. Lade- und Lesefehler werden angezeigt; das Zahnrad lässt sich danach erneut verwenden.
