# c9n 0.9.36

Unter Einstellungen → Hosting standen beim Update zwei Knöpfe auf einmal: „Auf neue Version aktualisieren“ und darunter schon die Rückfrage mit „Update jetzt starten“ und „Abbrechen“. Jetzt steht dort zuerst nur ein Knopf. Die Rückfrage („Jetzt auf … aktualisieren? Die Installation wird dafür vorübergehend angehalten.“) erscheint erst nach dem Klick darauf.

Wer ein Update „Ohne Sicherung“ startet, sieht im Verlauf den Schritt „Daten sichern“ nicht mehr, weil nichts gesichert wird. Das kurze Anhalten der Anwendung gehört dann zum Schritt „Neue Version starten“. Dafür meldet der Update-Dienst jetzt, ob mit oder ohne Sicherung gearbeitet wird; ein älterer Update-Dienst tut das noch nicht, dann gilt die Wahl auf der Seite.

Erweiterungen (Einstellungen → Erweiterungen) lassen sich jetzt auch auf Installationen mit Docker Snap installieren. Dort lehnte der Container-Start die Erweiterung ab, die Installation brach mit „Die Erweiterung ist nach dem Start nicht gesund“ ab und wurde zurückgenommen. Die Erweiterungen folgen jetzt derselben Einstellung wie der Kern (`C9N_NO_NEW_PRIVILEGES`, vom Installer auf Docker Snap automatisch gesetzt).

Prozess-Ansicht „Arbeiten“: Das × an einer markierten Verbindung tut jetzt etwas. Es öffnet den Entwurf und entfernt oder benennt die Verbindung dort um, mit Rückgängig. Eine neu gewählte Karte bleibt nicht mehr grau, während die Nachbarkarte hell bleibt. Im Kartenmenü fehlen die Einträge „Nach links/rechts/oben/unten verschieben“ (verschieben geht weiter mit Shift und Pfeiltasten), und der Detailbereich schließt mit einem Symbol.

GitHub: Unter Einstellungen → GitHub verbindet die Administration den Arbeitsraum mit einem Token (schreibgeschützt, es wird nichts auf GitHub geändert). Skript-Karten wählen ihre Repositories dann aus der Liste dessen, was das Token sieht. Das Modul „GitHub“ lässt sich unter Einstellungen → Module ausschalten.
