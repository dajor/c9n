# c9n 0.9.40

**Einstellungen: Texte und Zustände stimmen mit dem Verhalten überein.** Die Seiten unter Einstellungen sagen jetzt, was wirklich passiert. „Hosting“ heißt überall „System & Updates“. Wer für eine Seite keine Rechte hat, sieht einen Hinweis, wer sie verwalten kann, statt stumm die Übersicht. Die Installationskonfiguration behauptet nicht mehr, im Browser lasse sich nichts ändern. Module nennen „An, nicht aktiv“ und sagen, wer sie installiert. Bei den Konto-E-Mails ist der c9n-Versand nur dann vorausgewählt, wenn er für diese Installation freigeschaltet ist; eine ausgegraute Testmail nennt den Grund. Jira nennt den Grund, wenn der automatische Abgleich grau ist. Das Speicherprotokoll steht in Klartext und kennt jetzt Sicherung und Fehler. Die MCP-Texte sagen, dass ein Update nur der Eigentümer mit Bestätigung starten kann. Die Seiten zeigen einen Ladezustand, solange die Eigentümerprüfung läuft, und melden einen Serverfehler, statt eine falsche Übersicht zu zeigen.

**Jira-Tickets: freigeben oder Änderungen anfordern.** Ein Ticket, das in Jira auf Freigabe wartet, kann direkt in c9n freigegeben oder mit kurzem Hinweis zurückgeschickt werden; c9n erkennt die Jira-Status selbst, die Administration kann sie unter Einstellungen → Jira korrigieren.

**Aufträge: Sprachübersicht.** „Alle Aufträge“ hat einen Schalter Aufträge | Sprachen. Die Sprachübersicht zeigt je Dokumentationsticket eine Zeile und je Sprache eine Zelle: Live, Wird veröffentlicht, Wartet auf Freigabe, Wird überarbeitet, Abgelehnt oder In Arbeit. Ein blockierter Arbeitsauftrag markiert seine Zelle als Gestört. Jede Zelle verweist auf den Auftrag oder das Jira-Ticket.

**Video: die genannte Person entscheidet.** Je Prozess wird eine Jira-Person genannt (ein c9n-Konto braucht sie nicht). c9n übernimmt eine Freigabe aus Jira nur von dieser Person und liest nur ihre Kommentare als Änderungswünsche. Auf der Seite des Laufs lassen sich Zeitpunkt und Sprache einer Stelle mit einem Klick notieren; die Wünsche gehen als eine Runde zurück. Stürzt der Arbeiter ab, legt er die Tickets seines Laufs nicht doppelt an, sondern ergänzt nur fehlende Dateien.

Hinweis: Bei einer Änderungsrunde im Video-Prozess entsteht noch ein neues Ticketpaar; das ist bekannt.
