# Design a better customer handover

**Problem:** Requests are passed between teams without a clear owner, complete information or a consistent response standard.

**Design blueprint:** Intake → identify missing information → draft a response → human decision → handover → record the outcome.

**Human responsibility:** Make commitments, handle exceptions and own the customer relationship.

**What exists:** Organisational design, role explanations, project links and workflow editors can be used to agree on this process. Specific runtime and external mailbox/CRM integrations must be assessed for each pilot.

**Status:** This is a proposed pilot blueprint, not a claim of a generally deployable end-to-end CRM automation.

**What to measure:** Human effort per request, number of handovers, avoidable rework, quality and clearly assigned responsibility before work starts.
