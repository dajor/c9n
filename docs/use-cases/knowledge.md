# From scattered ideas to reviewed knowledge

**Problem:** Useful notes and feedback are collected, then disappear into separate tools. People cannot tell which source supports a decision.

**Journey:** Capture a note or text PDF → organise it → review the suggestion → store the approved result → create a follow-up task or briefing.

**Human responsibility:** Check the source, correct the summary and decide where the information belongs. AI output is a proposal until reviewed.

**What exists:** A bounded knowledge workflow, source versions, private-by-default entries, explicit sharing, human review and follow-up tasks. Automated organisation requires a configured supported model; manual organisation can be tried without one.

**What is still open:** General video/audio import, OCR, embeddings and broad multi-source retrieval.

**What to measure:** Review effort, corrections, source reuse and completed follow-up tasks. Do not equate the time a task waits in a queue with human working time.
